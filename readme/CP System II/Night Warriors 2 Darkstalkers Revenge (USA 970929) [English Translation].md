Night Warriors 2 Darkstalkers Revenge USA 970929 English Translation by strygo:

        [Details]

            Vampire Hunter 2 only ever reached Japanese arcades. Its predecessor came
            west as Night Warriors: Darkstalkers' Revenge, but the sequel never did.
            This patch translates the whole game into English under the Western name
            it should have had, Night Warriors 2. The title screen is not a fan
            mock-up: an unused Western title path was already in the ROM, and the
            patch finishes it and switches it on. Gameplay is unchanged.

            Where Capcom's own English wording exists in the Western Darkstalkers
            games, the patch reuses it. Everything else is freshly translated and
            checked in-game.

        [Changes]

            - Arcade-native Night Warriors 2 title screen and English staff roll
            - USA region presentation (warning screen and region byte)
            - Western character names on character select, route map and fight HUD:
              Zabel -> L.Raptor, Gallon -> J.Talbain, Lei-Lei -> Hsien-Ko,
              Phobos -> Huitzil, Aulbath -> Rikuo
            - English route and stage titles
            - All 225 post-fight quotes, all boss dialogue and every ending in English

        [Setup]

            - Requires the stock, unmodified vhunt2.zip in games/mame
              (split sets also need qsound.zip). Nothing on the card is modified;
              the translation is applied in memory as the game loads.
            - Runs on Jotego's jtcps2 core.
            - Saves and settings use their own name, nwarr2en, so the original
              game's settings are untouched.
